# Grafiska element – översikt

De grafiska elementen är verktygen vi använder för att kommunikationen ska kännas som SmFF – inte bara se ut som SmFF. De är hämtade ur det småländska landskapet och folkrörelsetraditionen.

> Grafiska element är verktyg, inte dekoration. Varje element används med avsikt – för att skapa kontrast, struktur, rörelse eller djup.

## De fyra småländska symbolerna

Bakom färgerna och formerna finns symboler som förankrar SmFF i vår historia och vår framtid.

| Symbol | Färg | Berättelse |
|---|---|---|
| 🦁 **Lejonet** | Smålandsröd | Styrka, samarbete, envishet – lejonet jagar i flock |
| 🌲 **Skogen** | Skogsgrön | Trygghet, uthållighet, framtidstro |
| ⛰️ **Myllan** | Torparbeige | Rötterna, historien, det erövrade jordstycket |
| ☀️ **Klarheten** | Linnevit | Öppenhet, transparens, folkrörelsens enkelhet |
