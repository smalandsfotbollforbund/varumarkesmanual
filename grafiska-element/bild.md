# Bildspråk

Bilderna ska kännas äkta och nära. De ska spegla människorna, miljöerna och glädjen i vår fotboll. Hellre vardag än uppstyltat – det enkla och jordnära är vårt uttryck.

> Varje bild vi publicerar är ett påstående om vad vi tycker spelar roll.

---

## Bildernas personlighet

SmFF:s bilder ska vara:

- **Jordnär** – verkliga människor i verkliga miljöer
- **Varm** – glädje, engagemang, gemenskap
- **Småländsk** – igenkännbara miljöer från vår geografi
- **Inkluderande** – alla åldrar, kön och bakgrunder representeras
- **Dynamisk** – det ska hända något: rörelse, interaktion, känsla

---

## Motivprioritetering

{% stepper %}
{% step %}
#### 1. Människorna (alltid prioritet 1)
Spelare, ledare, domare, föräldrar, funktionärer – fotbollens vardagshjältar. Ansikten med känsla. Det oarrangerade ögonblicket väger tyngre än den arrangerade grupposösen.
{% endstep %}

{% step %}
#### 2. Ögonblicket
Firandet, ansträngningen, samtalet, skrattet, tårarna. Det som gör fotboll meningsfullt.
{% endstep %}

{% step %}
#### 3. Det småländska rummet
Grusplaner, trädfodrade sidolinjer, enkla omklädningsrum, landsvägar till avsides belägna planer. Det är vår miljö – och vi är stolta över den.
{% endstep %}

{% step %}
#### 4. Spelet
Spelögonblick, taktikbräda, träning. Fotboll i rörelse.
{% endstep %}
{% endstepper %}

## Bildmanéret

{% tabs %}
{% tab title="Naturalistisk (primärt)" %}
Äkta färger, naturligt ljus, ingen tung efterbehandling. Bilderna ska se ut som de är tagna av någon som var på plats.

**Tillåten justering:** Lätt exponering, kontrast, beskärning.\
**Aldrig:** Drastisk färghantering, artificiella filter, AI-genererade bilder.
{% endtab %}

{% tab title="Röd duplexton (sekundärt)" %}
För framträdande kommunikation – affischomslag, nyhetsbrevshuvud, sociala medier.

**Specifikation:** Konvertera till svartvitt → applicera overlay i Smålandsröd `#A91C1C` med blandningsläget "Multiply" vid 60–80 % opacitet.
{% endtab %}

{% tab title="Svartvitt (tertiärt)" %}
I redaktionella sammanhang, inuti längre trycksaker och för historiska bilder. Skapar variation och en dokumentär känsla.
{% endtab %}
{% endtabs %}

## Principer att undvika

- Alltför stylade eller "stockiga" bilder utan lokal förankring
- Modellliknande positurer och arrangerade grupposer utan naturlighet
- Överdriven retusch som tar bort känslan av närvaro
- Tomma arenor eller miljöer utan människor
- Bilder som exkluderar – enbart herrar, enbart ungdomar, enbart elit
- **AI-genererade bilder i alla former** – det är det motsatta av äkta
- Bilder med konkurrenters logotyper synligt

## Tekniska krav

| Användning | Minsta upplösning |
|---|---|
| Webb och sociala medier | 72 dpi, min 1 200 px på längsta sidan |
| Tryck (broschyr, affisch) | 300 dpi vid slutlig storlek |
| Stor format (vepa, banderoll) | 150 dpi vid slutlig storlek |

**Leveransformat:** Digitalt: JPG eller PNG · Tryck: TIFF eller JPG i CMYK, 300 dpi · Logotyper: alltid SVG eller EPS – aldrig JPG.

## GDPR och bildsamtycke

Alla bilder på identifierbara individer kräver samtycke. Bilder på minderåriga kräver samtycke från **vårdnadshavare**. SmFF:s standardformulär för bildsamtycke finns hos distriktschefen.

Alla bilder som publiceras ska:
1. Ha ett klart fotorättsläge – ägande eller licens dokumenterat
2. Följa GDPR – samtycke inhämtat
3. Lagras i förbundets bildbank med metadata (fotograf, datum, plats, rättighetsstatus)
