# Designelement & toning

## Myللtoningen – det bärande designelementet

SmFF:s centrala designelement är en **organisk toning** som visualiserar övergången från den steniga åkern (Torparbeige/Smålandsröd) till skogen (Skogsgrön). Det är SmFF:s eget svar på SvFF:s blågula toning – och ska upplevas på samma sätt: levande, böljande, aldrig statisk eller linjär.

{% hint style="success" %}
**Kopplat till attributet Framåt:** Toningen visualiserar rörelse och förändring. Den är aldrig stillastående – precis som vi.
{% endhint %}

---

## Regler för toningen

{% tabs %}
{% tab title="Form" %}
**Aldrig linjär.** Toningen ska uppfattas som mjukt böljande – använd radial eller friform gradient, aldrig linjär.

**Alltid från en kant.** Toningen växer ut från en kant eller ett hörn av ytan – aldrig centralt placerad på bildytan.

**Aldrig för platt.** Den ska uppfattas som levande och oberäknelig – i ständig rörelse och utveckling.
{% endtab %}

{% tab title="Proportioner" %}
| Primärfärg i toningen | Fördelning |
|---|---|
| Smålandsröd primär | Röd max 70 % · Grön/beige min 30 % |
| Skogsgrön primär | Grön max 60 % · Röd/beige min 40 % |

Proportionerna speglar SmFF:s övergripande färgregel: röd är alltid primär i den röd-gröna kompositionen.
{% endtab %}

{% tab title="Bildläge" %}
Opacitet vid bildsättning: **60–80 %** – bilden under ska fortfarande vara läsbar.

Toningen kan med fördel användas för att täcka delar av en rörig bild och tydliggöra textbudskap.
{% endtab %}
{% endtabs %}

## Toningens användningsområden

- Bakgrundselement på affischer, omslag och framsidor
- Över fotografier för SmFF:s bildmanér
- Avdelarband i trycksaker och presentationsslides
- Dekorativt element i bildkanter

## Ramar

Ramar används som designelement runt fotografier och informationsblock. De skapar tydlighet och ordning i kommunikation med högt informationsinnehåll – och kopplar till fotbollsplanens linjering.

### Bildramar

**SmFF:s bildram är alltid i Smålandsröd.** Den används i kommunikation där bilder är i fokus – affischer, matchkommunikation, omslag.

**Konstruktion:**

{% stepper %}
{% step %}
#### Placera bilden i sin arbetsyta (100 %)
{% endstep %}

{% step %}
#### Skala ner bilden till 90 %
Den frigjorda ytan bildar ramen runt bilden.
{% endstep %}

{% step %}
#### Justera tjockleken
På icke-kvadratiska format: justera de bredare sidornas ramar så att tjockleken är enhetlig på alla fyra sidor.

Ramens tjocklek: max hälften av bredden på bokstaven "i" i den största texten som ramar in.
{% endstep %}
{% endstepper %}

### Informationsramar

Informationsramar används runt faktablock, datum och praktisk information som ska lyftas fram.

- Rektangulär form – alltid
- Enkel linje i Stenmursgrå eller Kolsvart mot ljus bakgrund, Linnevit mot mörk bakgrund
- Ingen ifylld bakgrundsfärg (undantag: Torparbeige i specifika sammanhang)
- **SvFF Trim används aldrig** inuti informationsramar – endast Stag Sans

## Lejonet som vattenmärke

Lejonet kan användas storskaligt som ett bakgrundselement – ett vattenmärke eller textur.

| Bakgrund | Opacitet |
|---|---|
| Vit bakgrund | 5–15 % |
| Röd eller grön bakgrund | 10–25 % |

- Alltid i den platta versionen (SmFF\_lejon\_platt)
- Aldrig bakom löpande brödtext – bara bakom rena ytor eller fotografier
- Kan klippas av kanten för en mer dynamisk komposition

## Vad vi undviker

{% hint style="danger" %}
- Hårda geometriska former utan koppling till fotboll eller Småland
- Drop shadows och 3D-effekter på grafiska element
- Gradients i fler än två färger – toningarna är alltid binära
- Dekorativa ramar med rundade hörn – SmFF:s ramar är alltid rektangulära
- Texteffekter (konturer, skuggor, glöd på typsnitt)
- Ornament och illustrationer som inte är lejonet, naturmotiv eller fotbollsrelaterade
{% endhint %}
