# Märket

Cirkelemblemet är vår officiella avsändare. Lejonet är vår identitetsbärare i fält. Tillsammans utgör de SmFF:s två röster — den formella och den emotionella.

## Systemet

{% tabs %}
{% tab title="Cirkelemblemet — Avsändare" %}
**Primär · Formell**

Tre delar som alltid hör samman: yttre ring, inre ring, lejonet med armborset. Aldrig separerade inom emblematiken. Detta är förbundets officiella signatur.

| --------------------- |
| Officiella dokument   |
