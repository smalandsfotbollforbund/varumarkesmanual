# Kombinationer

## Kombinationsexempel

{% tabs %}
{% tab title="Kampanj — SvFF Trim i block" %}
Kampanjformatet är systemets starkaste uttryck.

```
SMÅLAND
BYGGER
FRAMÅT
```

Stor rubrik i SvFF Trim Bold. Full bredd. Mot Smålandsröd bakgrund. Nyckelord i Matchgul som accent. Lejonet som vattenmärke vid 10–15 % opacitet. Inga kompromisser.

SvFF Trim Bold i tunga rubrikblock. Stora versaler, trångt radavstånd, ingen utfyllnad. 80-talet uppstår genom rytmen — inte genom typsnittet.
{% endtab %}

{% tab title="Editorial — citat-stil" %}
Editorialformatet är SmFF:s mer reflekterande röst.

> _"Bakom varje match finns någon som kritar linjer och kokar kaffe."_

Stag Sans Book Italic i stor storlek — ett citat som tar halva sidan. Torparbeige bakgrund. SvFF Trim-rubrik i Skogsgrön ovanför. Avsändaren i Semibold under citatet.

DM Serif Italic (webbersättning för Stag Sans Book Italic) används sparsamt — för manifest och citat som bär värme. Aldrig i kombination med SvFF Trim på samma rad.
{% endtab %}
{% endtabs %}
