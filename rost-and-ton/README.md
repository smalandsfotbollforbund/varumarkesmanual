# Röst & ton

## Grundrösten

Vi skriver som smålänningar pratar. Direkt, utan omvägar, med respekt för den vi talar med. Vi är inte ett marknadsföringsteam utan ett förbund som faktiskt gör saker.

Korta meningar slår långa. Konkreta ord slår abstrakta. Datum, tider och platser är alltid med. "Snart" och "i närtid" är ord vi undviker.

## Språkprinciper

| Vi säger             | Istället för                                        |
| -------------------- | --------------------------------------------------- |
| Genomföra / göra     | Implementera                                        |
| Förbättra            | Optimera                                            |
| Erbjuda / ge         | Tillhandahålla                                      |
| Arbeta för           | Verka för                                           |
| Bygger               | Faciliterar                                         |
| Föreningarna         | Stakeholderbas                                      |
| Skriv kort och rakt  | Skriv byråkratiskt när det går att skriva mänskligt |
| Datum, tid, plats    | Snart / i närtid                                    |
| Vi gör               | Vi strävar mot att möjliggöra                       |
| Kvalitet är ett krav | Vi strävar efter hög kvalitet                       |
