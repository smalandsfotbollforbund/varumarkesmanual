# Vår röst

Vår röst (tonalitet) ska kännas jordnära, trygg och framåtblickande. Vi vill spegla småländsk envishet och värme, samtidigt som vi visar riktning och bygger framtidstro.

<table data-view="cards"><thead><tr><th></th><th></th></tr></thead><tbody><tr><td><strong>Småländskt jordnära</strong></td><td>Vi använder enkla ord som alla förstår, utan onödiga krångligheter. Vi står med båda fötterna i myllan.</td></tr><tr><td><strong>Trygg och tydlig</strong></td><td>Vi ger raka besked, men alltid med omtanke. Folk ska känna att de kan lita på oss.</td></tr><tr><td><strong>Charmig och folklig</strong></td><td>Vi har glimten i ögat, vi kan skämta till det ibland och vi pratar som människor – inte som en byråkrat.</td></tr><tr><td><strong>Framåtriktad</strong></td><td>Vi pratar om utveckling, lösningar och nya vägar. Även när vi blickar tillbaka, gör vi det för att lära och bygga vidare.</td></tr><tr><td><strong>Samarbetsinriktad</strong></td><td>Vi säger ofta ”vi” – för framgången skapas tillsammans.</td></tr></tbody></table>

## Exempel i praktiken

| Inte såhär                                                                   | Utan såhär                                                              |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| ”Vi implementerar digital transformation för att optimera administrationen.” | ”Vi gör det enklare för ledare, så att mer tid kan läggas på spelarna.” |
| ”Smålands Fotbollförbund tillhandahåller administrativa verktyg.”            | ”Vi frigör tid så att fotbollen kan ta mer plats i vardagen.”           |
