# Ordbruk

## Ordbruk

**Ordlistan är bindande i all kommunikation i distriktets namn.** Kärnan:

| Skriv                                    | Skriv aldrig                                |
| ---------------------------------------- | ------------------------------------------- |
| Genomföra / göra                         | Implementera                                |
| Förbättra / effektivisera                | Optimera                                    |
| Erbjuda / ge                             | Tillhandahålla                              |
| Goda erfarenheter / lärdomar             | Best practice                               |
| Berörda / föreningarna / medlemmarna     | Stakeholders                                |
| Samarbete                                | Synergier                                   |
| Stärka                                   | Empowera                                    |
| Ta initiativ / ligga steget före         | Vara proaktiv                               |
| Ber inte om ursäkt                       | Apologiserar                                |
| Ange konkret datum eller period          | "Löpande", "snart", "i närtid"              |
| Ledare / tränare / domare / plan / match | Coach / referee / pitch / game (på svenska) |

**Inkluderande språk:** "Spelare" framför "pojk- och flickspelare" när det inte är specifikt. "Ledare" inkluderar tränare. "Alla" framför "samtliga". Aldrig "man" som neutralt pronomen. Skriv "du", "vi" eller "hen".
