# Vårt varumärke

Detta är Smålands Fotbollförbunds varumärkesmanual. Varumärket består av fyra pelare. All kommunikation i distriktets namn hämtar sina beslut här. Distriktschefen äger varumärkesmanualen och dess utformning, och beslutar om avvikelser och uppdateringar.

{% hint style="info" %}
**Manualen är bindande.** Reglerna är beslut, inte förslag. Exempel är markerade som exempel. Är du osäker frågar du distriktschefen före publicering, inte efter.
{% endhint %}

#### Jag ska göra något. Var börjar jag?

| Uppgift                                    | Läs                                                                         |
| ------------------------------------------ | --------------------------------------------------------------------------- |
| Skriva ett inlägg, en nyhet eller ett mejl | [Så låter vi](rost/sa-later-vi.md) och [Referensröst](rost/referensrost.md) |
| Göra en grafik, affisch eller presentation | [Tillämpningar](tillampningar.md) och [Färg](visuell-identitet/farg.md)     |
| Välja rätt logotyp                         | [Märket](visuell-identitet/market.md), beslutstabellen                      |
| Välja, beställa eller publicera bilder     | [Bildspråk](visuell-identitet/bildsprak.md)                                 |
| Kolla vad ett ord heter hos oss            | [Ordbruk](rost/ordbruk.md)                                                  |
| Göra en sista koll före publicering        | [Rätt & fel](ratt-and-fel.md)                                               |

#### De fyra pelarna

1. [**Positionering**](positionering/)**.** Vilka vi är, vem vi talar till och vad vi står för.
2. [**Röst**](rost/)**.** Hur vi låter, i alla kanaler.
3. [**Visuell identitet**](visuell-identitet/)**.** Färg, skrift, märke, element och bild.
4. [**Berättelsen**](berattelsen/)**.** Ursprunget, genomlinjen och bevisen.

#### Genomlinjen

> Det som byggs för hand i Småland håller i generationer, och fotbollen är inget undantag.

#### Bondetestet

Före varje produktion:

1. Gör vi mer än nödvändigt?
2. Är det vi gör gjort ordentligt?
3. Skulle vilken lagledare som helst i Småland förstå det?
